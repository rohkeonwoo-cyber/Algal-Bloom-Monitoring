# data/

GitHub Actions가 매시간 자동으로 채우는 폴더입니다 (수동으로 편집하지 마세요).

| 파일 | 내용 | 출처 |
|---|---|---|
| `hrfco_waterlevel.json` | 낙동강 유역 수위관측소 최신 수위·유량 + 관심/주의/경계/심각 기준수위 | 한강홍수통제소 |
| `hrfco_rainfall.json` | 낙동강 유역 강수관측소 최근 1시간·24시간 누적 강수량 | 한강홍수통제소 |
| `hrfco_fldfct.json` | 현재 발령 중인 홍수예보(없으면 빈 배열) | 한강홍수통제소 |
| `algae_latest.json` | 조류경보제 4개 지점 최신 관측값 + 발령단계 판정 | 국립환경과학원(data.go.kr) |

각 파일에는 `updated_at`(KST) 필드가 있어, 페이지에서 "최근 갱신 n분 전"을 표시하는 데 씁니다.
