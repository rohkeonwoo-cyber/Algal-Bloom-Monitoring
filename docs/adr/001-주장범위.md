# ADR-001 · 절대 농도를 제공하지 않고 상대 강도로 표현한다

- 상태: 채택
- 날짜: 2026-09-16

## 맥락

위성 기반 Chl-a 추정 모델의 성능은 측정소 단위 GroupKFold 교차검증에서 다음과 같다
(`chla/outputs/run_log.txt`, DS0 · 3×3 창 · XGBoost, N=592, 측정소 25곳, 2016-11 ~ 2025-08).

| 지표 | 값 |
|---|---|
| R² | 0.543 |
| RMSE | 12.2 mg/m³ |
| MAE | 7.88 mg/m³ |
| 최대 오차 | 51.5 mg/m³ |

RMSE 12.2 mg/m³는 **조류경보 단계 하나를 건너뛸 수 있는 크기**다. 지도에 "32.4 mg/m³"라고
표기하면 실제 값이 20일 수도 45일 수도 있다는 뜻이며, 소수점 표기는 없는 정밀도를 있는 것처럼
보이게 만든다.

성능이 낮은 원인은 고농도 표본 부족이다. 602개 표본 중 50 mg/m³ 초과가 약 62개뿐이라,
모델이 가장 잘 맞혀야 할 구간의 학습 근거가 가장 얇다. 표본이 늘지 않는 한 재학습으로
해결되지 않는다.

동시에 **물환경정보시스템 실측값이 공개되어 있어 누구나 반증할 수 있다.** 틀린 숫자를 내면
검증당한다.

반면 같은 모델이 "여기가 저기보다 진하다"는 순위 정보는 상당 부분 보존한다. 이 비대칭이
이 결정의 근거다.

## 결정

화면을 두 층으로 나눈다.

| 층 | 출처 | 표현 | 주장 강도 |
|---|---|---|---|
| 배경 히트맵 | 위성 추정 | 5등급 (낮음~매우 높음), **숫자 없음** | 상대적 분포 |
| 지점 마커 | 실측 + 조류경보 단계 | 값과 관측일자 표기 | 관측된 사실 |

- UI 문구에서 "추정 농도"를 쓰지 않는다. **"상대 강도(위성 추정)"**로 적는다.
- 범례는 수치 구간이 아니라 등급 이름으로 둔다.
- 신뢰도는 화소 단위가 아니라 **장면 단위**로 표시한다(구름 비율, 관측 경과일, 학습 분포 밖 여부).
- README에 "이 서비스가 주장하지 않는 것" 절을 두고 위 수치를 그대로 공개한다.

**2026-09-16 추가** — Phase 0 측정(ADR-009) 결과 **"25 mg/m³ 초과 가능성"** 한 가지를 더
주장할 수 있게 되었다(AUC 0.897, 재현율 0.794, 정밀도 0.773). 단계 하나짜리 이진 표시까지만
쓰고, 확률값이나 농도값으로는 표기하지 않는다.

**50 mg/m³ 이상(고농도) 탐지는 여전히 주장하지 않는다** — 재현율 0.222 로, 심한 상황을
놓치는 방향의 오차다. "고농도 아님"으로 보여도 실제로는 심할 수 있다는 점을 화면에 밝힌다.

## 검토했으나 버린 안

**절대 농도값 표기.** 실측이 공개되어 반증 가능하고, R² 0.54를 근거로 내세울 수 없다.
도메인을 아는 사람에게는 신뢰를 잃는 표기다.

**이상탐지만으로 구성.** 평년 대비 편차는 모델 편향이 기준선에도 들어가 상쇄되므로 가장
방어하기 쉬운 표현이지만, 다년 기준선 산출이 선행되어야 해서 첫 화면까지 오래 걸린다.
별도 레이어로 나중에 얹기로 한다(ADR-003 참조).

## 결과

**좋아지는 것**
- 모델 성능이 오르지 않아도 서비스가 정직하게 성립한다.
- 한계를 UI 설계로 흡수한 판단이 남으므로 설명할 거리가 생긴다.

**나빠지는 것**
- "농도를 알려주는 서비스"라는 직관적 매력을 포기한다.
- 사용자가 구체적 수치를 원할 때 실측 지점으로만 안내해야 한다.

## 재검토 조건

- 고농도(50 mg/m³ 초과) 표본이 현재의 3배 이상 확보되어 재학습 결과 RMSE가 경보 단계 폭보다
  뚜렷이 작아질 때.
- 분류 성능(ADR-009의 통과선)이 충분히 높아, 등급이 아니라 "초과/미초과" 판정을 주장할 수
  있게 될 때.
