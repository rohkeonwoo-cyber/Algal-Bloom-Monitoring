# 의사결정 기록 (ADR)

이 폴더는 이 프로젝트에서 내린 설계 판단과 그 근거를 한 건씩 남긴다.
"무엇을 골랐는가"보다 **"왜 그것을 골랐고, 무엇을 버렸는가"**를 남기는 것이 목적이다.

각 문서는 같은 틀을 쓴다.

- **맥락** — 판단이 필요했던 상황과 측정된 사실
- **결정** — 무엇을 하기로 했는가
- **검토했으나 버린 안** — 그리고 버린 이유
- **결과** — 이 결정으로 좋아진 것과 나빠진 것
- **재검토 조건** — 어떤 사실이 바뀌면 이 결정을 다시 볼 것인가
