# ADR-005 · 상시 무료 클라우드에 서빙하고, 무거운 배치는 연구실 GPU가 맡는다

- 상태: 채택
- 날짜: 2026-09-16

## 맥락

**제약: 이 프로젝트에 운영비를 쓰지 않는다.** (개인 프로젝트이며 수익이 없다.)

**연구실 공용 서버 실측** (2026-09-16)

| 항목 | 값 |
|---|---|
| CPU / RAM / GPU | 64코어 / 125 GB / RTX PRO 6000 96 GB |
| 디스크 | 937 GB (791 GB 여유) |
| 사용자 | 5명 공유 |
| sudo | **불가** (비밀번호 필요) |
| 컨테이너 런타임 | 설치되어 있지 않음 |
| 외부 바인드 포트 | **22번뿐** |
| `unprivileged_userns_clone` / subuid | **1 / `gw:231072:65536` 할당됨** |
| 가동 이력 | 2026-09-04 부팅, 재부팅이 실제로 일어남 |

즉 sudo 없이도 rootless 컨테이너의 사전조건은 충족되지만, **외부에 서비스를 공개할 경로가
없고 교내망 정책 확인이 필요하며, 공유 서버라 재부팅·자원경합을 통제할 수 없다.**

**클라우드 요금 조사 결과** (2026-09-16)

| 구성 | 월 비용 |
|---|---|
| **Oracle Always Free (홈 리전 서울)** | **0원** |
| Oracle 유료 최소 구성 | 34,190원 |
| 국내 3사(NCP·카카오·NHN) 동급 구성 | 50,544 ~ 88,812원 |

Always Free 제공량: ARM 2 OCPU / 12 GB, 블록 200 GB, 오브젝트 20 GB, **아웃바운드 월 10 TB**,
공인 IP 과금 항목 없음. 필요량(연 0.33 GB 저장, 타일 트래픽) 대비 여유가 크다.

## 결정

```
Oracle Always Free (서울, 0원)  ─ FastAPI · 타일서버 · PostGIS · 수집 배치
        ↑ 산출물 push (단방향)
연구실 서버 (0원)               ─ 다년 기준선 · 모델 학습 · 대량 재처리 (GPU)
GitHub Pages (0원)              ─ 정적 프론트 · CI
```

- 클라우드가 **상시 서빙과 수집**을 맡는다. root 권한이 있으므로 정식 Docker를 쓴다.
- 연구실 서버는 **무거운 계산만** 맡고 결과를 밀어 올리기만 한다. 외부에서 들어오는 연결이
  없으므로 방화벽·교내망 정책 문제가 생기지 않는다.
- 온프레미스 GPU에서 계산하고 클라우드에서 서빙하는 구성은 실무에서 흔한 패턴이다.

**가입 시 홈 리전을 반드시 서울로 지정한다.** 춘천 리전은 Always Free ARM 인스턴스 대상에서
제외되어 있고, 홈 리전은 이후 변경할 수 없다.

## 검토했으나 버린 안

**연구실 서버 + 터널(Tailscale Funnel 등)로 공개.** 비용 0이고 GPU를 그대로 쓰지만,
(a) 교내망 정책 확인이 선행되어야 하고 (b) 공유 서버라 가용성을 통제할 수 없으며
(c) 클라우드 배포·운영 경험이 남지 않는다. **ARM 인스턴스 확보에 실패하거나 카드 등록이
불가할 경우의 폴백으로 남긴다.**

**국내 사업자 유료 VM.** 월 5만~8.9만원. 비용 제약에 어긋난다. 격차의 주원인은 VM 단가가
아니라 아웃바운드 요금(국내 3사 GB당 90~100원 vs Oracle 10 TB까지 0원)이며, 타일 트래픽이
있는 이 서비스에서는 차이가 계속 벌어진다.

**완전 정적 구성(서버 없음).** 장애 요소가 없지만 동적 타일서버·검색 API·화면범위 다운로드를
포기해야 한다(ADR-004). 최후 폴백.

## 결과

**좋아지는 것**
- 비용 0으로 상시 가용한 공개 URL을 확보한다.
- 구성 전체가 컨테이너이므로 다른 클라우드로 그대로 옮길 수 있다.

**나빠지는 것**
- 무료 등급이라 사양이 작고(ARM 2 OCPU/12 GB), 제공 정책이 바뀔 위험을 감수한다.
- **ARM64 아키텍처**이므로 타일서버·PostGIS 이미지의 멀티아키 지원을 확인해야 한다.
- 가입에 신용카드 등록이 필요하다(과금은 되지 않으나 등록 자체는 요구된다).
- 두 곳에 나뉘므로 산출물 전달 경로와 그 실패 처리를 따로 만들어야 한다.

## 재검토 조건

- ARM 인스턴스 용량을 확보하지 못할 때 → 폴백(연구실 서버 + 터널)으로 전환.
- Always Free 제공 조건이 축소될 때 (과거 4 OCPU/24 GB에서 2 OCPU/12 GB로 이미 축소된 전례가 있다).
- 트래픽이나 계산량이 무료 등급을 넘어설 때.
