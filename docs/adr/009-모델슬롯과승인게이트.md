# ADR-009 · 모델을 교체 가능한 슬롯으로 두고, 승인 기준을 코드로 강제한다

- 상태: 채택 (통과선 측정 완료 2026-09-16)
- 날짜: 2026-09-16

## 맥락

당초 계획은 "Phase 0(위성 기반 녹조 탐지 성능 검증)을 끝낸 뒤 사이트를 만든다"였다.
연구 순서로는 타당하지만 두 가지 문제가 있다.

**첫째, 통과 기준이 정해져 있지 않으면 검증이 끝나지 않는다.** 이 문서를 쓸 당시 측정된 것은
회귀 지표(R² 0.543, RMSE 12.2)뿐이었고, 분류 성능은 계산된 적이 없었다
(`chla/outputs/run_log.txt` 확인). 즉 "경보 수준 초과를 잡아내는가"라는 질문 자체가 측정되지
않은 상태였다. **아래 "측정 결과"에서 이 공백을 메웠다.**

**둘째, 성능이 크게 오를 가능성이 낮다.** 원인이 고농도 표본 부족(602개 중 50 mg/m³ 초과
약 62개)이므로 재학습으로 해결되지 않는다. 여기에 서비스 착수를 걸어두면 프로젝트가 멈춘다.

## 결정

**모델을 파이프라인의 교체 가능한 슬롯으로 둔다.**

`모델 버전 → 산출물 → 검증 지표 → 게시 여부`를 데이터로 관리한다.

- Phase 0 통과 전에는 슬롯에 **규칙 기반 지수(NDCI/MCI)**가 들어간다. 서비스는 돌아간다.
- 통과하면 XGBoost 모델로 교체된다. **교체 절차 자체가 기능이다.**
- 승인 기준은 문서가 아니라 **코드로 강제**한다. 지표가 기준선에 못 미치면 게시되지 않는다.

**Phase 0 통과 기준 (사전 등록)**

회귀 R²가 아니라 서로 다른 세 축으로 판정한다.

| 축 | 측정 | 통과선 |
|---|---|---|
| ① 경보 초과 판정 | 임계값 초과 이진 분류, 측정소 단위 GroupKFold | 재현율 ≥ 0.7, 정밀도 ≥ 0.5, AUC ≥ 0.8 |
| ② 공간 순위 재현 | 같은 날짜 여러 지점의 실측 순위 vs 추정 순위 | Spearman ρ ≥ 0.6 (날짜별 중위값) |
| ③ 시간 방향 일치 | 연속 관측 사이 증가/감소 방향 일치율 | ≥ 70% |

①은 "초과/미초과"를 주장할 수 있는지를, ②는 상대 분포 표현(ADR-001)의 근거를,
③은 시계열 슬라이더(ADR-010)의 정당성을 각각 뒷받침한다.
**②만 통과하고 ①이 미달이면, 그것이 곧 ADR-001의 등급 표현을 유지할 근거가 된다.**

**미달일 때의 폴백** — 서비스는 단계적으로 내려갈 뿐 멈추지 않는다.

1. 실측 관측망 + 경보 단계 지도 (위성 없이 성립)
2. 위성은 NDCI/MCI 지수 자체를 상대 강도로 표출하고, 모델이라 부르지 않는다
3. 슬롯은 비워 두되 인터페이스는 유지한다

## 측정 결과 (2026-09-16)

`analysis/phase0_분류지표.py` 로 측정했다. DS0 · 3×3 창 · XGBoost, 측정소 단위 GroupKFold 의
**out-of-fold 예측**만 사용한다(저장된 모델을 학습자료에 그대로 쓰면 성능이 부풀려진다).

계산 경로 검증 — 논문 보고값이 재현된다.

| 지표 | 논문 | 재현 |
|---|---|---|
| GroupCV R² | 0.543 | 0.545 |
| RMSE | 12.2 | 12.17 |
| MAE | 7.88 | 7.86 |

**① 경보 초과 판정**

| 임계값 | 양성 | AUC | 재현율 | 정밀도 | 판정 |
|---|---|---|---|---|---|
| **25 mg/m³** | 223/592 (37.7%) | **0.897** | **0.794** | **0.773** | **통과** |
| 50 mg/m³ | 45/592 (7.6%) | 0.900 | 0.222 | 0.500 | **미달** |

50 기준은 AUC 가 0.900 인데 재현율이 0.222 다. **순위는 매기지만 값을 충분히 크게 예측하지
않는다**는 뜻이며, 고농도 표본이 45건뿐인 것과 일관된다. 녹조가 심한 상황을 놓치는 방향의
오차라 특히 주의해야 한다.

**② 공간 순위 재현** — 날짜 78개, 중위 Spearman **0.600**(통과선과 같음), 평균 0.540,
하위 25% 0.400, 양의 상관 90%. **통과했으나 여유가 없다.**

**③ 시간 방향 일치** — 연속 관측 566쌍 중 **81.3%** 일치. **통과.**

### 판정

**모델 슬롯을 규칙 기반(NDCI/MCI)에서 XGBoost 로 승격할 수 있다.** 단 주장 범위는
**상대 강도(ADR-001) + "25 mg/m³ 초과 가능성"** 까지다. 절대 농도와 **고농도(50 이상) 탐지는
여전히 주장하지 않는다.**

### 이 측정이 답하지 못한 것

세 지표 모두 **측정소 지점의 매칭 자료**에서 나왔다. 측정소는 25곳뿐이고 대부분 본류 중앙이다.
**강 전체 화소로 일반화되는지는 측정된 적이 없다.** 지도 전면의 화소 단위 신뢰도를 주장하려면
다른 검증이 필요하다.

## 검토했으나 버린 안

**Phase 0를 먼저 끝내고 착수(기존 계획).** 연구로는 깔끔하나, 통과 기준이 없고 성능 상승
여지가 작아 착수 시점이 불확실해진다.

**모델 없이 규칙 기반으로만 영구 운영.** 구현은 단순하지만 모델 연동 경험이 남지 않는다.

## 결과

**좋아지는 것**
- 모델 검증 결과와 무관하게 서비스가 배포된다.
- 승인 기준이 코드에 있으므로, 성능 미달 모델이 조용히 게시되는 일이 없다.
- 검증 지표가 산출물과 함께 기록되어 재현 가능해진다.

**나빠지는 것**
- 슬롯·지표·게시 여부를 관리하는 구조가 추가된다.
- 규칙 기반과 모델 기반 두 경로를 한동안 함께 유지해야 한다.

## 재검토 조건

- 고농도(50 mg/m³ 이상) 표본이 늘어 ① 의 50 기준 재현율이 오를 때 — 그때 고농도 탐지를
  주장할 수 있다.
- 화소 단위 검증 수단이 생길 때(항공·현장 동시 관측 등).
- ② 가 통과선과 같은 0.600 이므로, 자료가 늘면 다시 재서 아래로 내려가는지 확인한다.
