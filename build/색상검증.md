# 심각도 배지 램프 검증

실시간 등급 표시(정상 / 관심 / 주의 / 경계 / 심각·대발생)에 쓰는 색을 눈대중으로
고르지 않고, OKLCH 에서 명도를 고르게 내려 생성한 뒤 **인접 등급끼리 실제로 구분되는지
수치로 확인**했다. 생성·검증 스크립트는 `색상검증.py`.

## 결과 (채택안)

| 등급 | hex | OKLab L (0–100) | 배지 글자색 |
|---|---|---|---|
| 정상 | `#7e8984` | 62.0 | 어두운색 (`#1a1f1d`) |
| 관심 | `#ffd95a` | 89.5 | 어두운색 (`#3a2c00`) |
| 주의 | `#e68920` | 71.4 | 어두운색 (`#301800`) |
| 경계 | `#b8381a` | 52.7 | 흰색 |
| 심각·대발생 | `#6e040b` | 34.1 | 흰색 |

## 인접쌍 분리 (OKLab 거리 ×100)

| 쌍 | ΔL | ΔE | 판정 |
|---|---|---|---|
| 정상 → 관심 | −27.5 | 31.1 | OK |
| 관심 → 주의 | +18.1 | 19.8 | OK |
| 주의 → 경계 | +18.7 | 20.3 | OK |
| 경계 → 심각 | +18.6 | 19.0 | OK |

최소 인접 ΔE = **19.0** (기준 15 이상). 경보 4등급은 명도가 단조 감소하므로
색각 이상이나 흑백 인쇄에서도 순서가 유지된다.

## 글자색 근거 (WCAG 대비)

| 등급 | 흰 글자 | 검은 글자 | 채택 |
|---|---|---|---|
| 정상 | 3.62:1 | 5.80:1 | 어두운색 |
| 관심 | 1.37:1 | 15.32:1 | 어두운색 |
| 주의 | 2.64:1 | 7.96:1 | 어두운색 |
| 경계 | 5.80:1 | 3.62:1 | 흰색 |
| 심각 | 12.46:1 | 1.69:1 | 흰색 |

## 색 이외의 인코딩

색만으로 등급을 전달하지 않는다. 배지에는 **항상 등급 글자**가 들어가고,
등급별 도형 아이콘(빈 원 / 찬 원 / 삼각형 / 팔각형)을 함께 붙였다.
지도 마커도 등급이 올라가면 크기가 커진다(정상 r=2.6 → 기준초과 r=6).

## 기각한 1차안 (기록)

처음 눈대중으로 잡은 `#e0a33c / #ec835a / #d1553a / #9e2b1e` 는
인접쌍 ΔE 가 9.2 / 11.5 / 13.9 로 전부 기준(15) 미달이었다.
명도 범위를 L 0.90→0.34 로 넓혀 재생성해 해결.

## 주의

이 프로젝트 환경에는 node 가 없어 dataviz skill 의 JS 검증기

Python 으로 직접 구현해 계산했다(`색상검증.py`). 값은 위 표 그대로 재현 가능하다.
